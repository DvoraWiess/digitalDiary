# מסמך אפיון: יומן שיעורים (גרסה מאושרת)

## א. תיאור הפרויקט

**שם:** יומן שיעורים (Lesson Diary)

**מטרה:** מערכת למורה שמלמדת קריאה בשיעורים פרטיים, לתלמידים שמתקשים בקריאה. המערכת מחליפה את הדפים ואת הבדיקות הידניות ביומן:
- סיכום דיגיטלי לכל שיעור.
- מעקב אחר שיעורים שהתקיימו ושלא התקיימו.
- תמונת מצב של כל תלמיד לפני שהוא מגיע.
- מעקב אחר שיעורי בית, כפי שהמורה בדקה בפועל.
- קביעת שיעורים בלי התנגשויות.

**משתמשים:**

| תפקיד | מי זה |
|---|---|
| מורה (`TEACHER`) | מנהלת המערכת. יש מורה אחת. |
| חשבון תלמיד (`STUDENT`) | חשבון לכל תלמיד, וההורה משתמש בו. המורה פותחת את החשבון. לשני אחים יש שני חשבונות נפרדים. |

**כניסה:** שם משתמש ייחודי באנגלית (למשל `cohen.dani`) וסיסמה.

## ב. מסכים

**מסכי המורה**

| מסך | מה מוצג ומה אפשר לעשות |
|---|---|
| התחברות | שם משתמש וסיסמה |
| רשימת שיעורים | נפתחת על היום. סינון לפי סטטוס (כולל "ממתין לאישור") ולפי טווח תאריכים. אישור, דחייה וביטול. |
| פרטי שיעור ודוח | פרטי השיעור, ביטול עם סיבה, כתיבה או עריכה של דוח |
| רשימת תלמידים | חיפוש לפי שם. פעילים קודם. |
| פרטי תלמיד ותמונת מצב | פרטים, הדוח האחרון (כולל "מה לעשות בשיעור הבא"), השיעור הקרוב ושיעורים אחרונים |
| הוספה ועריכה של תלמיד | כל הפרטים, פרטי כניסה, השבתה ואיפוס סיסמה |
| זמינות | שעות עבודה שבועיות, וזמנים מיוחדים (לכולם או לתלמיד מסוים) |

**מסכי ההורה (חשבון תלמיד)**

| שיעורים | שיעורים קרובים ושיעורים שהיו, וביטול |
| דוח שיעור | מה למדו, התנהגות, שיעורי בית והמלצה על תגבור |
| קביעת שיעור | שבוע של זמנים פנויים (עד 4 שבועות קדימה) ושליחת בקשה |
| שינוי סיסמה | |

## ד. מסד נתונים

**קשרים:** חשבון אחד (`User`) לכל תלמיד (`Student`), קשר של 1:1. לתלמיד יש כמה שיעורים (`Lesson`), 1:N. לכל שיעור יש דוח אחד לכל היותר (`LessonReport`), 1:0..1. זמן מיוחד (`SpecialSlot`) יכול להיות מיועד לתלמיד אחד, N:0..1. שעות העבודה (`WorkingHours`) לא קשורות לטבלה אחרת.

### User: חשבונות כניסה
| שדה | טיפוס | חובה | הערה |
|---|---|---|---|
| id | Int | ✅ | PK, מספור אוטומטי |
| role | Enum: TEACHER / STUDENT | ✅ | |
| username | String | ✅ | ייחודי, אותיות קטנות |
| passwordHash | String | ✅ | bcrypt, לא מוחזר ב-API |
| createdAt, updatedAt | DateTime | ✅ | אוטומטי |

### Student: תלמידים
| שדה | טיפוס | חובה | הערה |
|---|---|---|---|
| id | Int | ✅ | PK |
| userId | Int | ✅ | FK ל-User, ייחודי (1:1), נמחק יחד איתו |
| firstName, lastName | String | ✅ | |
| age | Int | ✅ | CHECK: בין 3 ל-18 |
| gradeText | String | ❌ | כיתה או מסגרת, טקסט חופשי |
| readingLevel | Enum: BEGINNER / BASIC / ADVANCED / FLUENT | ✅ | ברירת מחדל BEGINNER |
| goals | String | ❌ | |
| schoolTeacherName, schoolTeacherPhone | String | ❌ | |
| parentName, parentPhone | String | ✅ | |
| teacherNotes | String | ❌ | רק המורה רואה |
| isActive | Boolean | ✅ | ברירת מחדל true. false חוסם את הכניסה. |
| createdAt, updatedAt | DateTime | ✅ | |

### WorkingHours: שעות עבודה שבועיות

### Lesson: שיעורים
| שדה | טיפוס | חובה | הערה |

## ו. התאמה לדרישות החובה

| דרישה | איך היא מתקיימת |
|---|---|
| התחברות | JWT דרך `POST /api/auth/login` |
| שני סוגי משתמשים | מורה וחשבון תלמיד (הורה), עם הרשאות שונות שנבדקות בשרת |
| אובייקט מרכזי עם לפחות 5 שדות | שיעור (Lesson), תלמיד (Student) ודוח שיעור. לכל אחד מהם יותר מ-5 שדות משמעותיים. |
| רשימת רשומות | רשימת שיעורים ורשימת תלמידים |
| הוספה | תלמיד, בקשה לשיעור, זמן מיוחד, דוח |
| עריכה | תלמיד, דוח, שעות עבודה, וסטטוס שיעור (אישור, דחייה, ביטול) |
| שדה בחירה | סטטוס שיעור, רמת קריאה, התנהגות, מצב שיעורי בית, נוכחות |
| חיפוש, סינון ומיון | חיפוש תלמיד לפי שם. סינון שיעורים לפי סטטוס וטווח תאריכים. מיון כרונולוגי. |
| מסד נתונים אמיתי | PostgreSQL עם Prisma, כולל migrations ואילוצי CHECK |

## החלטות מרכזיות מהאפיון

- רק ההורה קובע שיעור, והמורה תמיד מאשרת. כך יש מסלול אחד ופשוט.
- כדי להזיז שיעור, המורה מבטלת עם סיבה, ואם צריך פותחת זמן מיוחד לתלמיד. ההורה קובע מחדש.
- המלצה על שיעור תגבור נכתבת בדוח, וההורה קובע.
- שיעורי הבית נבדקים על ידי המורה בשיעור, ולכן לא תלויים בדיווח של התלמיד.
- תלמיד שסיים ללמוד מסומן כלא פעיל. ההיסטוריה שלו נשמרת, והכניסה שלו נחסמת.
